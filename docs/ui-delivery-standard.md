# AI 宝宝营养师 UI 交付与验收规范 V1.0

## 1. 设计基准

- 小程序布局宽度：`750rpx`。
- 主验收视口：`375 × 812px`，即 `1px = 2rpx`。
- 补充视口：`390 × 844px`、`393 × 852px`、`430 × 932px`。
- 页面必须适配状态栏、胶囊按钮及 `safe-area-inset-bottom`。
- 视觉基线：`Sketch/1首页.png` 至 `Sketch/6每日营养报告页.png`。

## 4. 设计系统

- 主色 `#ff6f70`，深主色 `#d95455`，浅主色 `#fff0ed`。
- 成功 `#69bd55` / `#eef8e8`，警告 `#f6a623` / `#fff4dc`。
- 主文字 `#2d2623`，次级文字 `#81736d`，弱文字 `#aaa09b`。
- 字号阶梯：`22 / 24 / 26 / 28 / 30 / 34 / 40 / 64rpx`。
- 间距阶梯：`8 / 12 / 16 / 20 / 24 / 32 / 40rpx`。
- 圆角阶梯：`12 / 16 / 20 / 28 / 999rpx`。
- 公共组件：`navigation-bar`、`app-tabbar`、`ui-card`、`status-pill`、`progress-ring`、`state-panel`。
- 禁止用 emoji、Unicode 符号或字体字符代替非系统图标；箭头、勾选、相机、导航图标使用 CSS 图形或正式图片资源。

## 5. 完整链路验收

主链路：`首页 → 拍照记录 → 识别结果 → 保存到今日记录 → 饮食记录 → 每日营养报告 → 宝宝档案 → 首页`。

每个跳转必须可返回；保存结果后记录页显示新增餐次反馈；所有不可用外部能力使用明确状态提示，不留“功能开发中”占位。

## 6. 强制视觉验收

1. 在主验收视口逐页截图。
2. 截图与对应 `Sketch` 图片缩放到相同内容宽度后，以 50% 透明度叠加。
3. 头像、主按钮、卡片边界、导航栏、取景框、评分和底部操作属于关键区域，边界误差必须 `< 4rpx`。
4. 字号、字重、颜色、圆角、阴影、图片裁切逐项检查。
5. 非系统文字/图标不得使用 Unicode 占位符。
6. 通过 375、390、430 三档宽度检查，不得横向溢出、遮挡或覆盖安全区。
7. 每页保存“基线、实现、叠加、差异说明”四项记录，未通过不得签收。

## 7. 完成定义

一页只有同时满足以下条件才算完成：默认状态可用、扩展状态可进入、主链路打通、视觉验收通过、真机点击区域合格、代码无临时图标和失效跳转。
